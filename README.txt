VIORI — сайт вязаных игрушек
=============================

Что внутри:
- index.html — структура сайта
- styles.css — дизайн и адаптация под телефон
- script.ts — исходный код логики сайта на TypeScript
- script.js — собранный файл для браузера (не редактируйте вручную)
- assets/viori-logo.png — логотип

Как открыть:
1. Распакуйте архив.
2. Откройте файл index.html двойным кликом.

Разработка:
1. Установите зависимости: npm install
2. Проверка типов: npm run check
3. Сборка TypeScript: npm run build

Администратор каталога:
- Первый зарегистрированный аккаунт получает роль администратора.
- В разделе «Управление» можно добавлять игрушки, цены, описания RU/EN и фотографии.
- В текущей демо-версии каталог хранится локально в браузере. Для публикации нужен сервер и база данных.

Тестовое оформление заказа:
- Корзина открывает форму адреса и доставки по Нидерландам.
- После оформления заказ появляется в кабинете клиента и разделе администратора.
- Администратор может менять статус заказа.
- iDEAL и банковская карта сейчас показаны как интерфейс: реальные платежи требуют подключения платёжного провайдера.

NFC-паспорта:
- Администратор выпускает уникальный код для конкретного персонажа.
- Ссылка активации имеет формат: index.html?nfc=УНИКАЛЬНЫЙ-КОД
- Паспорт может быть привязан только к одному клиентскому аккаунту.
- Владелец открывает цифровой паспорт и добавляет главы семейной истории.
- В демо-версии защита работает локально; на релизе реестр кодов должен храниться только на сервере.

Юридическая подготовка:
- legal.html содержит условия продажи, возвраты, privacy/NFC/cookie policy и статус безопасности.
- В футере есть постоянная кнопка онлайн-отмены заказа.
- Cookie banner сохраняет отдельный выбор необходимых или аналитических cookies.
- Перед запуском обязательно заполните юридическое имя, адрес, email, KVK и BTW-id.
- Нельзя менять статус безопасности на подтверждённый до реальных испытаний и CE-документации.

GitHub + Supabase:
1. Создайте пустой GitHub-репозиторий и добавьте его как remote origin.
2. Добавьте GitHub Secrets: SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_ACCESS_TOKEN, SUPABASE_DB_PASSWORD, SUPABASE_PROJECT_REF.
3. Workflow CI проверяет каждый push, Deploy website публикует ветку main на GitHub Pages.
4. Workflow Apply Supabase migrations запускается только вручную и применяет файлы из supabase/migrations.
5. Для локального подключения скопируйте config.example.js в config.js и укажите URL проекта и public anon key.
6. Никогда не добавляйте service_role key или пароль базы в config.js, исходный код либо Git.

Что нужно заменить перед публикацией:
1. Номер WhatsApp:
   - Откройте script.ts, затем выполните npm run build.
   - Найдите: const WHATSAPP_NUMBER = "31000000000";
   - Вставьте настоящий номер без + и пробелов.
2. Ссылку WhatsApp в index.html:
   - Найдите https://wa.me/31000000000
3. Ссылку Instagram:
   - Найдите https://instagram.com/
4. Фото игрушек:
   - Сейчас стоят красивые заглушки.
   - Можно заменить каждый блок <div class="product-image placeholder ..."> на:
     <div class="product-image">
       <img src="assets/имя-фото.jpg" alt="Название игрушки">
     </div>
5. Названия, цены и описания игрушек.
